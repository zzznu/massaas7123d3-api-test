massaas7123d3 API Test

massaas7123d3 API Test is a private command-line client for the Pinterest API v5. It is operated by one individual security researcher (Bugcrowd handle massaas7123d3) who takes part in Pinterest's bug bounty program on Bugcrowd.

The client sends API requests with OAuth tokens of Pinterest test accounts that the researcher created and controls, in order to check how the API enforces authentication, OAuth scopes and access control. Findings are reported to Pinterest through Bugcrowd.

It is not a product or a service. Nobody else can sign up for it or use it, and it is not offered to businesses or the public.
