Privacy Policy – massaas7123d3 API Test

Effective date: 22 November 2026

Who operates this app

massaas7123d3 API Test ("the app") is operated by one individual security researcher (Bugcrowd handle massaas7123d3), not by a company. It is used only for security research under Pinterest's bug bounty program on Bugcrowd. Contact: massaas7123d3+a@bugcrowdninja.com.

Who uses the app

Only the researcher. The app has no sign-up, no end users and no customers. The only Pinterest accounts that authorize the app are test accounts created and controlled by the researcher.

What data the app accesses

Through the Pinterest API the app reads and writes data of those test accounts only: account and profile information, boards and Pins, ad accounts and their campaigns, audiences, catalogs and reports, and the OAuth access and refresh tokens issued for those accounts.

The app is not meant to access data of any other Pinterest user. If a response ever contains information about a person or account that is not one of the researcher's test accounts, testing of that request stops, the information is not used or shared, it is deleted, and the issue is reported to Pinterest through Bugcrowd as the program rules require.

How the data is used

Only to test the security of the Pinterest API and to write vulnerability reports for Pinterest. It is not used for advertising, profiling or analytics, and it is not sold.

Where the data is stored and who receives it

Tokens, requests and responses are stored on the researcher's own computer. They are shared with Pinterest and Bugcrowd as part of vulnerability reports. The researcher uses AI coding assistants operated by third-party providers (for example Anthropic) to run and analyze tests, so requests and responses of the test accounts may be processed by those providers on the researcher's behalf. The researcher does not use this data to train AI models. The data is not given to anyone else.

Retention and deletion

Tokens are deleted when testing ends or when the app is removed. Requests and responses are kept only as long as they are needed as evidence for a report and are deleted after the report is resolved.

This website

This website is a static page with no cookies, forms or analytics added by the researcher. It is hosted on GitHub Pages; GitHub may log visitors' IP addresses as described in the GitHub Privacy Statement.

Changes and requests

If this policy changes, the new version and its effective date are published on this page. Questions and deletion requests can be sent to the contact address above.
